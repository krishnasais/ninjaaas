TrainBookingApp is a web-based train ticket booking system that allows users to search for available trains, book tickets, and manage reservations.

📌 Features
User registration & authentication
Train search and filtering by route, date, and time
Ticket booking & cancellation
Payment gateway integration
Admin dashboard to manage trains, schedules, and bookings
Responsive UI for desktop & mobile
🛠️ Technologies Used
Frontend: Java Swing
Backend: Java
Database: MySQL
